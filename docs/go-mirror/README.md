# Go mirror patches

Patches for `../flowcatalyst-go` that mirror rulings the owner gave on the
Java port, so the two implementations do not drift while both exist. They
are generated by editing a scratch copy of the Go working tree, building it
(`go build ./...`, `go vet`), running the affected test packages, and
diffing back. Apply from the Go repo root:

```
git apply /Users/andrewgraaff/Developer/flowcatalyst-javalin/docs/go-mirror/<file>.patch
```
